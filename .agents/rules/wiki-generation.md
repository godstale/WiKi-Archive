# 문서 생성 및 관리 지침

## 1. 디렉토리 구조 및 파일 명명 규칙
- **디렉토리 구조:** `[topic]/wiki/` 패턴을 사용합니다. (예: `restaurants/wiki/`)
  - 이는 `wiki-hub`가 특정 토픽의 `wiki/` 폴더만을 대상으로 동작할 수 있게 하기 위함입니다.
- 모든 문서 파일명(H1)은 타이틀과 동일하게 설정합니다.
- 특정 주제(entities, concepts)는 해당 폴더 내에 분류하여 저장합니다.
- 관련 문서 간의 링크(Internal Linking)를 권장합니다.

## 2. 미디어 첨부
- 모든 이미지는 해당 토픽의 `wiki/images/` 디렉토리에 저장 후 상대 경로로 참조합니다.

## 3. 데이터 업데이트 가이드 (HOW-TO-UPDATE.md)
- 모든 Topic은 `HOW-TO-UPDATE.md`를 포함해야 합니다.
- 이 파일에는 데이터 소스(URL, API 정보)와 추출 방법, 업데이트 주기를 명시합니다.
