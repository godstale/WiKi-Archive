# 위키 생성 세부 규칙

## 1. 문서 구조
- 모든 문서는 제목(H1)으로 시작해야 합니다.
- 섹션은 H2, H3를 사용하여 논리적으로 구분합니다.
- 관련 문서 간의 상호 링크(Internal Linking)를 권장합니다.

## 2. 미디어 처리
- 이미지는 `wiki/images/` 폴더에 저장하고 상대 경로로 참조합니다.
- 외부 이미지는 가급적 로컬로 다운로드하여 관리합니다.

## 3. 업데이트 가이드 (HOW-TO-UPDATE.md)
- 모든 Topic은 `HOW-TO-UPDATE.md`를 포함해야 합니다.
- 이 파일에는 해당 위키를 최신으로 유지하기 위한 구체적인 데이터 소스(URL, API 등)와 추출 방법이 명시되어야 합니다.
